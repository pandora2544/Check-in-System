## ขั้น 2 — จองห้อง 🟡 (ถัดไป)

หลักการ: **ระบุห้องให้คาบเรียน = จองห้อง** (ดู plan.md หัวข้อ 4)

- ✅ ออกแบบโครงข้อมูล `room_reservations` + กฎห้ามจองซ้อน + trigger ซิงก์จากคาบเรียน
- ✅ ร่าง migration 014 (`supabase/migrations/20261005000014_room_reservations.sql`)
- ✅ ข้อมูลจำลอง: ย้าย CHM102L ไปห้องทดสอบ C (พิกัดเดียวกับห้อง A) — ไม่มีคาบชนเหลือ
- ❓ **apply migration 014** — รอผู้ใช้อนุมัติ (ครั้งแรกถูกยกเลิก 5 ต.ค.)
- ⬜ ตั้งค่าเทอม: ห้องชน = บล็อก, ตรวจกับการจองทุกประเภท, ลำดับบันทึก ลบ→แก้→สร้าง, ห้ามช่วงเวลาทับกันในกลุ่มเดียวกัน, แปล error 23P01
- ⬜ Edge Function `booking`: rooms_board, booking_preview, booking_create (ครั้งเดียว/ซ้ำรายสัปดาห์), booking_cancel (ครั้งนี้/ทั้งชุด)
- ⬜ สอนชดเชย: เลือกคาบที่งด → วันใหม่ → สร้างคาบ + ย้ายบท
- ⬜ หน้า "🏫 ห้อง" (`#rooms/<date>`): ตารางห้องว่าง (ห้อง × เวลา), กดช่องว่างเพื่อจอง, กดบล็อกดูรายละเอียด/ยกเลิก, ใช้ได้บนมือถือ
- ⬜ ปฏิทินเดือน/วัน แสดงการจองนอกตาราง
- ⬜ ทดสอบกับฐานข้อมูลจริง + อัปเดต test-guide
- ❓ คำถามจองห้อง 4 ข้อ (plan.md หัวข้อ 6) — ระหว่างนี้ใช้ค่าเริ่มต้นใน plan.md 4.4

## ขั้น 3 — คลังวัสดุสิ้นเปลือง ⬜

- ❓ **รายการวัสดุจากผู้ใช้** (ชื่อ, ขนาด/สเปก, หน่วย, ประเภท, คงเหลือ, ราคา, วันหมดอายุ)
- ⬜ บทบาทใหม่ "นักวิทยาศาสตร์/เจ้าหน้าที่ห้องแล็บ"
- ⬜ ตาราง: รายการของ (หน่วยซื้อ/หน่วยใช้/อัตราแปลง/ขนาดบรรจุ), ล็อต, ที่เก็บ, รายการเคลื่อนไหว (บัญชีคลัง)
- ⬜ ฟังก์ชันฐานข้อมูลแบบ transaction: รับเข้า, จอง, เบิก, คืน, ปรับยอด, ตัดจำหน่าย, ย้าย
- ⬜ หน้าคลัง: รายการ + ยอด (มีจริง/จอง/ใช้ได้), รับของ, เบิก, ตรวจนับ, ประวัติ
- ⬜ นำเข้าจาก Excel (รายการ + สต็อกตั้งต้น)
- ⬜ เตือนใกล้หมด/ใกล้หมดอายุทาง Telegram

## ขั้น 4 — แม่แบบใบงาน ⬜

- ❓ ใบงานจริงของแต่ละบท + สูตรเตรียม + คำตอบคำถามใบงาน 7 ข้อ
- ⬜ แม่แบบใบงานต่อบท: บล็อก, รายการ + กฎจำนวน (ต่อกลุ่ม/คน/ห้อง/สาธิต/คาบ/เตรียม/% เผื่อ), ช่วงวันเรียน/วันอ่านผล
- ⬜ สูตรเตรียม (ของที่เตรียม → วัตถุดิบในคลัง)
- ⬜ พิมพ์ใบงาน (แม่แบบหน้าตา 2 แบบแรกจากบท 1 และบท 6)

## ขั้น 5 — ใบงานของคาบ ⬜

- ⬜ คำนวณจำนวนจากรายชื่อ/กลุ่ม/ห้องย่อย (ก่อนมีรายชื่อใช้จำนวนที่นั่งรับ)
- ⬜ ยืนยัน → จองของในคลัง → งานเตรียมของของนักวิทย์ (วันที่ต้องเสร็จ, แจ้งเตือน)
- ⬜ เบิกจริง / คืนของเหลือ / ของเสีย → ปิดคาบ
- ⬜ เชื่อมเช็คชื่อ: จำนวนคนมาจริง, ยืม-คืนรายกลุ่ม (ทางเลือก: สแกนออกไม่ได้ถ้ายังไม่คืนของ)

## ขั้น 6 — ต้นทุน ⬜

- ⬜ ต้นทุนวัสดุจริงต่อคาบ → บท → วิชา → เทอม → หัว นศ. (+ ของเสีย/หมดอายุแยก)
- ⬜ ต้นทุนการจองนอกคาบลงโครงการ/วิจัย
- ⬜ พยากรณ์ของที่ต้องใช้ทั้งเทอม − สต็อก = รายการขอซื้อ
- ❓ วิธีคิดต้นทุน (FIFO/เฉลี่ย), รวมค่าเสื่อมไหม

## ขั้น 7 — ครุภัณฑ์ ⬜

- ⬜ จองเวลาเครื่อง (ใช้กลไกเดียวกับจองห้อง), ยืม-คืนรายกลุ่ม, ชั่วโมงใช้งาน, ค่าเสื่อม

Prototype ใช้งานจริง — เช็คชื่อด้วยใบหน้า + GPS

ทำงานจริงทั้งกล้อง/GPS/liveness/การจับคู่ใบหน้า — ย้ายมาใช้ Human library แทน face-api.js เดิมแล้ว (face-api.js ถูกเลิกดูแลไปแล้วตามที่เจาะลึกไว้) ไม่มี backend จริง ข้อมูลเก็บในหน่วยความจำ รีเฟรชหน้าแล้วหาย ลงทะเบียนได้หลายคนใน session เดียวกัน ตอนเช็คชื่อ**ไม่ต้องเลือกว่าเป็นใคร** ระบบจะหาคนที่ตรงที่สุดให้เอง — หมายเหตุ: ค่า threshold การจับคู่/liveness ยังเป็นค่าตั้งต้นที่ยังไม่ได้ปรับจูนกับอุปกรณ์จริง ถ้าเจออาการเช็คชื่อผ่านยากไปหรือง่ายไป บอกได้เลยจะช่วยปรับให้

## ขั้นตอนทดสอบ

1. แท็บ **ทดสอบ** → ใส่รหัสเครื่องมือทดสอบ → กด **ตั้งที่นี่** (ย้ายห้อง A/B มาที่ตำแหน่งปัจจุบัน)
2. แท็บ **ลงทะเบียนหน้า** → ใส่รหัส เช่น `66010001` → ตรวจสอบ → ติ๊กยินยอม → สแกน
3. แท็บ **เช็คชื่อ** → กดเช็คชื่อ
   - ภายใน 15 นาทีแรกของชั่วโมง = **ปกติ** หลังจากนั้น = **สาย**
   - เช็คซ้ำคาบเดิม = "เช็คชื่อคาบนี้ไปแล้ว" (รอชั่วโมงถัดไปเพื่อทดสอบใหม่)

## ทดสอบตั้งค่าเทอม (หน้าอาจารย์ > ⚙️ ตั้งค่าเทอม)
ลำดับที่ควรทำจริง: ห้อง/วันหยุด → วันเวลาเรียน → บทปฏิบัติการ → บทของแต่ละคาบ → (นำเข้ารายชื่อหลังนักศึกษาลงทะเบียน)
| กรณี | ทำอย่างไร | ผลที่ควรได้ |
|---|---|---|
| วันหยุด (แอดมิน) | 🎌 วันหยุด → เพิ่มวันที่ + ชื่อ → บันทึก | ตอนดูตัวอย่างคาบ วันนั้นขึ้นใน "ข้ามวันหยุด" |
| ห้อง (แอดมิน) | 🏫 ห้อง/พิกัด → ยืนในห้องแล้วกด "📍 ใช้ตำแหน่งตอนนี้" → บันทึก | ห้องใหม่เลือกได้ในช่วงเวลาเรียน |
| สร้างคาบทั้งเทอม | เปิดกลุ่ม → ① เพิ่มช่วงเวลา (เช่น ทุกวันอังคาร 13:00–16:00 ห้อง A) → ดูตัวอย่างคาบ → ยืนยัน | จำนวนคาบตรงกับจำนวนสัปดาห์ ไม่มีคาบในวันหยุด/วันที่ผ่านมาแล้ว → เห็นในปฏิทิน |
| ห้องชน | ตั้งเวลาให้ทับวิชาอื่นในห้องเดียวกัน | กรอบแดง "ห้องชนกับวิชาอื่น" (ยังบันทึกได้) |
| เลื่อนเวลา | เปลี่ยน 13:00 → 13:30 แล้วดูตัวอย่าง | เป็น "ปรับคาบเดิม" ไม่ใช่ลบ-สร้างใหม่ · บทที่ตั้งไว้ยังอยู่ |
| ลบวันเรียน | ลบช่วงเวลาหนึ่งออก | แสดง "ลบ n คาบ" ต้องกดยืนยันสองครั้ง · คาบที่มีคนเช็คชื่อแล้วไม่ถูกลบ (🔒) |
| บทปฏิบัติการ | ② วางรายการบท เช่น "1 ความปลอดภัย / 2 การกลั่น" → บันทึกบท | ได้บทเรียงเลข ใช้ร่วมทุกกลุ่มของวิชา |
| บทรายคาบ | ③ "เติมบทตามลำดับ" (ติ๊กทำทุกกลุ่มได้) หรือเลือกเองทีละคาบ → บันทึกแผน | หน้าวัน/หน้าคาบขึ้น 🧪 บทที่ n · ใบเซ็นชื่อขึ้น "ปฏิบัติการที่ n เรื่อง …" · Telegram มีบรรทัดบท |
| งดคาบ | ติ๊ก "งด" + หมายเหตุ "หยุดชดเชย" → บันทึกแผน | คาบหายจากปฏิทิน ลำดับคาบถัดไปเลื่อน |
| อาจารย์ไม่ใช่ผู้สอน | instructor2 เปิดกลุ่มของ instructor1 | ดูได้อย่างเดียว ปุ่มแก้ถูกปิด |

## ค่าที่ต้องจดระหว่างทดสอบ (ใช้ปรับจูน)
หน้าผลลัพธ์แสดง `ใบหน้า` (cosine similarity, ผ่านที่ ≥ 0.60) และ `real` (antispoof, ผ่านที่ ≥ 0.60)
จดค่าของคนจริง/คนอื่น/รูปถ่าย บนมือถือหลายรุ่น เพื่อตั้งเกณฑ์ที่เหมาะสม

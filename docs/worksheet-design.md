## 2. กฎการคิดจำนวน — ตรวจกับตัวเลขจริงแล้ว

สูตรเดียวใช้ได้กับทุกแถว (2 ห้อง ห้องละ 7 กลุ่ม):

```
แจกจ่าย = Σ ทุกห้อง ( ต่อกลุ่ม × จำนวนกลุ่มในห้อง
                     + ต่อคน × จำนวนนักศึกษาในห้อง
                     + ต่อห้อง
                     + ชุดสาธิตต่อห้อง )
         + ต่อคาบ (คงที่)
รวม     = แจกจ่าย + เตรียมล่วงหน้า (ถ้านับรวม)
สั่ง/เตรียมจริง = ปัดขึ้นตามขนาดบรรจุ( รวม × (1 + % เผื่อ) )
```

| แถวในใบงานจริง | กฎ | ระบบคำนวณ | ในใบงาน |
|---|---|---|---|
| บท 1 หลอด NB | 4/กลุ่ม + สาธิต 4/ห้อง | 64 | 64 ✓ |
| บท 1 ตะแกรงหลอด | 2/กลุ่ม + สาธิต 1/ห้อง | 30 | 30 ✓ |
| บท 1 ตู้บ่มเชื้อ | 1/ห้อง | 2 | 2 ✓ |
| บท 6 MacConkey | เตรียม 12 (นับรวม) + 1/กลุ่ม + สาธิต 1 | 28 | 28 ✓ |
| บท 6 TSB+3%NaCl | เตรียม 8 (นับรวม) + 1/กลุ่ม + สาธิต 1 | 24 | 24 ✓ |
| บท 6 TSI | เตรียม 12 (**ไม่**นับรวม) + 4/กลุ่ม + สาธิต 4 | 64 | 64 ✓ |
| บท 6 MR-VP | เตรียม 20 (**ไม่**นับรวม) + 8/กลุ่ม + สาธิต 8 | 128 | 128 ✓ |
| บท 6 กล้องจุลทรรศน์ | 2/กลุ่ม | 28 | 28 ✓ |
| บท 6 ชุด Oxidase | 2/ห้อง | 4 | 4 ✓ |
| บท 6 เชื้อ Unknown | 1/กลุ่ม + สาธิต 1/ห้อง | 16 | 16 ✓ |

**ข้อสังเกต:** คอลัมน์ "เตรียม Lab" ในบทที่ 6 มี 2 ความหมายปนกัน — บางแถวบวกเข้ายอดรวม (MacConkey, TSB) บางแถวไม่บวก (TSI, MR-VP, Gram, Oxidase) ในระบบจึงต้องแยกให้ชัดว่ารายการเตรียมล่วงหน้านั้น **ใช้ทำอะไร** (เช่น ใช้เลี้ยงเชื้อแจก, ทำชุดสาธิตผลบวก/ลบ, ทดสอบ Lab ก่อน) และนับรวมยอดหรือไม่ — ต้องยืนยันกับผู้ใช้

## 3. หลักการออกแบบ: แยก "ข้อมูล" ออกจาก "หน้าตา"

- **ข้อมูล** ของทุกบทเก็บโครงเดียวกัน: รายการ + กฎการคิด + รายละเอียด
- **หน้าตาใบงาน** = เลือกว่าจะมีบล็อกอะไร เรียงอย่างไร แต่ละบล็อกแสดงคอลัมน์ไหน
- ใบงานบท 1 กับบท 6 จึงเป็น "ข้อมูลเดียวกัน คนละการจัดวาง" — วิชาอื่น (เคมี ฟิสิกส์ ชีววิทยา) ก็ใช้โครงเดียวกันได้ แค่เลือกคอลัมน์/หมวดต่างกัน
- มี **แม่แบบหน้าตา (preset)** ให้เลือก เช่น "แบบบทที่ 1", "แบบบทที่ 6" และบันทึกแม่แบบใหม่ได้


## 7. ลำดับพัฒนา (ใหญ่ไปเล็ก)

1. **บทปฏิบัติการ + ช่วง + บล็อกข้อความ** — แอดมินกรอกชื่อบท/สิ่งที่ทำ/สาธิต ผูกกับคาบในตารางเรียน
2. **คลังรายการของ** (นำเข้าจากรายการที่ผู้ใช้จะส่งมา) + **บล็อกรายการพร้อมกฎการคิด**
3. **ออกใบงานอัตโนมัติ** (Word/PDF) + แม่แบบหน้าตา 2 แบบแรกจากบท 1 และบท 6
4. **งานเตรียมของนักวิทย์** + แจ้งเตือนตามวันกำหนด
5. **สต็อก** (จอง/ตัด/ของใกล้หมด) + ครุภัณฑ์ชนเวลา
6. **ต้นทุน** เชื่อมจำนวนคนมาเรียนจริง
